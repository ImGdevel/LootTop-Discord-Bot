# LoopTop Study Bot

스터디 그룹을 위한 Discord 봇. 매일 인증, 주간 목표, 리더보드, 포인트 시스템을 제공한다.

**스택:** Cloudflare Workers + D1 (SQLite) · TypeScript · Discord Components V2

---

## 핵심 기능

### 📋 일일 인증
매일 공부한 내용을 인증 쓰레드에 카드 형태로 기록한다.

- 인증 내용, 달성률(0~100%), 증빙 이미지(최대 10장), URL 첨부 가능
- 당일 인증에 한해 **수정 / 삭제** 버튼 제공
- 삭제 시 포인트 자동 회수

### 🪙 포인트 시스템
인증마다 포인트를 자동 지급한다.

| 조건 | 포인트 |
|---|---|
| 평일 인증 | 100p |
| 주말 인증 | 150p |
| 주 5회 평일 인증 달성 | +300p 보너스 |

### 🏆 리더보드
주간 달성률 기준 순위를 자동 집계한다.

- 동률 시 이번 주 획득 포인트 → 인증 수 순으로 타이브레이크
- 공동 순위(🥇🥇) 지원
- 매주 자동 발행 (Cron)

### 👤 프로필
나의 누적 포인트, 이번 주 달성률, 평일 보너스 진행도, 전체 인증 횟수를 확인한다.

### 📌 주간 목표
포럼 채널에 주간 목표를 작성하고 팀과 공유한다.

## 슬래시 명령어

| 명령어 | 설명 |
|---|---|
| `/홈` | 인증·리더보드 바로가기 허브 |
| `/인증` | 오늘 인증 등록 |
| `/목표` | 주간 목표 작성 |
| `/리더보드` | 이번 주 순위 확인 |
| `/프로필` | 내 포인트·달성률 확인 |
| `/휴가` | 휴가 신청 |
| `/설정` | 서버 설정 (관리자) |
| `/버전` | 현재 배포 버전 확인 |

## 로컬 실행 및 배포

```bash
npm ci                    # 의존성 설치
npm run dev               # 로컬 실행 (wrangler dev)
npm run register          # 슬래시 명령어 등록
npm run ship              # 마이그레이션 + 명령어 등록 + 배포
```

환경 변수는 `.env.discord`에 설정하고, 배포용 시크릿은 `scripts/register-secrets.mjs`로 Cloudflare에 등록한다.

## 채널 구조

봇 최초 실행 시 필요한 채널을 자동 생성한다.

| 채널 | 용도 |
|---|---|
| `#스터디-홈` | 메인 허브 |
| `#인증` | 일일 인증 쓰레드 |
| `#목표` | 주간 목표 포럼 |
| `#리더보드` | 주간 순위 포럼 |
| `#알림` | 인증 리마인드 |
| `#휴가` | 휴가 신청 |
