# LoopTop Discord Bot MVP Specification

## 1. 문서 목적

이 문서는 LoopTop Discord Bot의 MVP 요구사항을 확정하기 위한 제품 명세서다.

MVP의 목표는 다음 세 가지를 디스코드 안에서 자연스럽게 운영할 수 있게 만드는 것이다.

- 주간 목표 작성
- 일일 인증 제출
- 주간 리더보드 집계

이 MVP는 `명령어 중심 봇`이 아니라 `채널 역할이 분리된 스터디 운영 앱`으로 설계한다.

## 2. 핵심 방향

- 기능은 채널별 역할에 따라 분리한다.
- 사용자는 가능하면 명령어보다 버튼, 카드, 모달 중심으로 사용한다.
- 목표 작성은 `주간 포럼 글`
- 인증 제출은 `일일 쓰레드`
- 리더보드는 `주간 리더보드 포럼 글`
- 명령어는 백업 진입점으로만 유지한다.

## 3. 채널 구조

MVP 기준 권장 채널 구조는 다음과 같다.

### 3.1 `#스터디-홈`

역할:

- 전체 기능의 메인 진입점
- 고정 홈 카드 제공
- 목표/인증/리더보드/설정 이동

비고:

- Discord는 사용자가 채널에 "입장"한 이벤트를 앱에 보내지 않으므로, 홈 채널이 없으면 UX가 급격히 불편해진다.

### 3.2 `#목표`

채널 유형:

- 포럼 채널

역할:

- 매주 생성되는 주간 목표 포럼 글 보관
- 참여자의 목표 카드 기록

### 3.3 `#인증`

채널 유형:

- 일반 텍스트 채널

역할:

- 매일 생성되는 인증 쓰레드 보관
- 각 참여자의 인증 기록 게시

### 3.4 `#리더보드`

채널 유형:

- 포럼 채널

역할:

- 주간 리더보드 포럼 글 생성
- 주간 결과 및 랭킹 기록

## 4. 목표 채널 요구사항

### 4.1 주간 포럼 글 생성

매주 일요일 `18:00`에 `#목표` 채널 안에 새로운 주간 포럼 글을 생성한다.

기본 제목 형식:

- `5월 4주차 (5/20 ~ 5/26)`

시간은 기본값이며, 추후 길드 설정에서 변경 가능해야 한다.

### 4.2 주간 포럼 글 첫 메시지

첫 메시지에는 다음이 포함된다.

- 이번 주 기간 안내
- 목표 작성 안내
- `내 목표 작성` 버튼

중요:

- 이 버튼 자체는 공개 메시지에 존재해도 된다.
- 버튼을 눌렀을 때의 응답과 작성 여부 확인은 사용자별로 처리한다.
- 이미 작성한 사용자가 다시 눌렀을 경우에는 `이미 작성됨` 또는 `목표 수정` 흐름으로 보낸다.

### 4.3 목표 유형

MVP에서 지원하는 목표는 `데일리 목표`만 포함한다.

`주간 목표`는 후속 단계에서 고려하며 MVP 범위에서는 제외한다.

### 4.4 데일리 목표

데일리 목표는 매일 수행하고 인증해야 하는 목표 항목이다.

예시:

- 매일 9시 기상
- 매일 6시간 이상 공부
- 책 읽고 스터디하기

각 목표 항목은 다음 인증 방식 중 하나 이상을 가진다.

- 텍스트 입력
- URL 입력
- 사진 업로드
- 체크형 인증

### 4.5 목표 작성 흐름

목표 작성은 단계형 입력 흐름으로 구성한다.

권장 단계:

1. 목표 항목 작성
2. 각 항목의 인증 방식 설정
3. 휴식일 선택
4. 최종 확인 및 완료

### 4.6 휴식일 설정

사용자는 이번 주 휴식일을 선택할 수 있다.

정책:

- 기본값은 `토요일`, `일요일` 선택
- 사용자는 기본값을 해제할 수 있다.
- 사용자는 평일을 휴식일로 추가할 수 있다.

휴식일로 지정된 날짜는 미인증이어도 실패로 계산하지 않는다.

### 4.7 목표 작성 완료 결과

목표 작성이 완료되면 해당 주간 포럼 글 안에 사용자의 목표 카드 메시지를 생성한다.

카드에는 최소한 다음 정보가 포함되어야 한다.

- 사용자명
- 이번 주 목표 목록
- 각 목표의 인증 방식
- 휴식일

## 5. 인증 채널 요구사항

### 5.1 일일 쓰레드 생성

매일 오전 `04:00`에 `#인증` 채널 안에 새로운 쓰레드를 생성한다.

기본 제목 형식:

- `5월 29일 인증`

시간은 기본값이며, 추후 설정에서 변경 가능해야 한다.

### 5.2 일일 쓰레드 첫 메시지

첫 메시지에는 다음이 포함된다.

- 오늘 인증 안내
- 제출 마감 시각 안내
- `오늘 인증` 버튼

### 5.3 인증 가능 기간

기본 정책:

- 해당 일자의 인증 쓰레드는 생성 시각부터 다음 날 `04:00`까지 유효
- 마감 이후에는 신규 인증 또는 수정 인증을 막는다
- 마감 이후 제출 시도는 리더보드에 반영되지 않는다

### 5.4 인증 폼

인증 폼은 사용자가 이번 주에 설정한 데일리 목표를 기준으로 동적으로 생성한다.

예:

- 목표가 3개면 인증 항목도 3개
- 목표별 인증 방식에 맞는 입력 UI 표시

정책:

- 모든 항목을 반드시 다 제출할 필요는 없다.
- 그날 실제로 수행한 것만 선택적으로 제출 가능하다.

### 5.5 추가 인증 및 수정

MVP에서는 `추가 인증 누적` 방식을 기본으로 한다.

의미:

- 사용자가 오전에 1차 인증
- 밤에 추가 달성 후 다시 인증
- 기존 인증을 지우지 않고 누적 기록

시스템은 해당 일자 내 기록을 모두 합산해 일일 달성 여부와 주간 누적치를 계산한다.

### 5.6 인증 완료 결과

인증 제출이 완료되면 해당 일일 쓰레드 안에 카드형 인증 메시지를 생성한다.

카드에는 최소한 다음 정보가 포함된다.

- 사용자명
- 인증 시각
- 오늘 달성한 목표 항목
- 항목별 인증 내용
- 첨부 URL 또는 사진

## 6. 리더보드 채널 요구사항

### 6.1 주간 리더보드 포럼 글 생성

매주 월요일 `00:00`에 `#리더보드` 채널 안에 새로운 포럼 글을 생성한다.

기본 제목 형식:

- `5월 4주차 리더보드`

생성 시각은 기본값이며, 추후 설정에서 변경 가능해야 한다.

### 6.2 리더보드 표시 내용

리더보드에는 최소한 다음 정보가 포함되어야 한다.

- 참여 인원 수
- 각 참여자의 목표 수
- 각 참여자의 실제 달성 수
- 각 참여자의 달성률
- 전체 랭킹

### 6.3 추가 랭킹

MVP에는 다음 추가 정보를 포함한다.

- 주간 달성률 Top 3
- 주간 달성률 Bottom 3

### 6.4 시각적 요구사항

리더보드는 텍스트만 나열하지 않는다.

최소 요구사항:

- 카드형 요약 영역
- 순위별 시각 구분
- 달성률 강조
- 참여자별 진행치 표시

## 7. 알림 정책

MVP 포함:

- 주간 목표 포럼 글 자동 생성
- 일일 인증 쓰레드 자동 생성
- 주간 리더보드 자동 생성

MVP 제외:

- 미인증 사용자 개인 DM 알림
- 마감 직전 개인 리마인드

## 8. MVP 범위 포함/제외

### 포함

- 채널별 기능 분리
- 주간 목표 포럼 글 생성
- 데일리 목표 작성
- 휴식일 선택
- 일일 인증 쓰레드 생성
- 목표 기반 동적 인증 폼
- 추가 인증 누적
- 주간 리더보드 자동 생성
- Top 3 / Bottom 3 표시

### 제외

- 주간 목표 다단계 달성치
- 개인 DM 리마인드
- 목표 자동 판정
- OCR 기반 이미지 검증
- 복잡한 포인트/레벨 시스템

## 9. 성공 기준

다음 조건을 만족하면 MVP 요구사항을 충족한 것으로 본다.

- 운영자는 별도 수작업 없이 주간 목표 글, 일일 인증 쓰레드, 리더보드 글을 자동 생성할 수 있다.
- 참여자는 명령어 없이 채널과 버튼 중심으로 목표와 인증을 제출할 수 있다.
- 목표와 인증이 실제 채널 구조 안에 기록으로 남는다.
- 리더보드가 목표 대비 달성률 기준으로 자동 집계된다.
