# Channel UX Flows

## 1. 문서 목적

이 문서는 LoopTop Discord Bot의 채널별 사용자 경험 흐름을 정의한다.

대상 채널:

- `#스터디-홈`
- `#목표`
- `#인증`
- `#리더보드`

## 2. 공통 UX 원칙

- 사용자는 명령어를 몰라도 주요 기능을 사용할 수 있어야 한다.
- 모든 핵심 액션은 버튼, 카드, 모달 중심으로 제공한다.
- 개인 입력 결과는 가능한 한 ephemeral 응답으로 반환한다.
- 공개 기록은 전용 채널 또는 쓰레드에 카드형 메시지로 남긴다.
- 각 채널은 역할이 명확해야 한다.

## 3. `#스터디-홈` UX 플로우

### 3.1 목적

`#스터디-홈`은 메인 진입 채널이다.

사용자는 이 채널에서 다음을 시작할 수 있다.

- 이번 주 목표 작성
- 오늘 인증
- 내 현황 확인
- 리더보드 보기
- 관리자 설정 진입

### 3.2 홈 카드 구성

홈 카드에는 다음 정보가 표시된다.

- 현재 주차
- 오늘 인증 쓰레드 링크
- 이번 주 목표 글 링크
- 이번 주 리더보드 링크
- 내 상태 요약

버튼 예시:

- `이번 주 목표`
- `오늘 인증`
- `내 현황`
- `리더보드`
- `새로고침`
- `서버 설정`

### 3.3 홈 채널 사용자 흐름

1. 사용자가 `#스터디-홈`으로 이동한다.
2. 고정된 홈 카드를 확인한다.
3. 필요한 버튼을 누른다.
4. 해당 채널 또는 모달 흐름으로 이동한다.

## 4. `#목표` UX 플로우

### 4.1 목적

`#목표`는 주간 목표 기록 채널이다.

형태:

- 포럼 채널

### 4.2 주간 글 생성 흐름

1. 매주 일요일 18:00에 새 포럼 글 생성
2. 제목: `5월 4주차 (5/20 ~ 5/26)`
3. 첫 메시지에 목표 작성 안내 카드 생성
4. `내 목표 작성` 버튼 제공

### 4.3 목표 작성 플로우

1. 사용자가 주간 포럼 글을 연다.
2. 첫 메시지의 `내 목표 작성` 버튼을 누른다.
3. 시스템이 사용자의 기존 작성 여부를 확인한다.
4. 미작성자면 목표 작성 흐름 시작
5. 작성자면 `이미 작성됨` 또는 `수정` 흐름 제공

### 4.4 목표 작성 Wizard

#### Step 1. 목표 항목 입력

사용자는 데일리 목표 항목을 작성한다.

예:

- 9시 기상
- 6시간 공부
- 독서 30분

#### Step 2. 인증 방식 지정

각 항목에 대해 인증 방식을 설정한다.

옵션 예:

- 텍스트
- URL
- 사진
- 체크

#### Step 3. 휴식일 선택

기본값:

- 토요일
- 일요일

사용자는 휴식일을 추가/해제할 수 있다.

#### Step 4. 확인 및 완료

작성한 목표 요약을 보여주고 완료한다.

### 4.5 완료 후 결과

1. 시스템이 해당 포럼 글 안에 사용자 목표 카드를 생성한다.
2. 사용자는 자신의 목표를 공개적으로 확인할 수 있다.
3. 이후 인증 플로우는 이 목표 구조를 참조한다.

## 5. `#인증` UX 플로우

### 5.1 목적

`#인증`은 일일 인증 기록 채널이다.

형태:

- 일반 텍스트 채널
- 매일 생성되는 일일 쓰레드 사용

### 5.2 일일 인증 쓰레드 생성

1. 매일 오전 04:00에 새 쓰레드 생성
2. 제목: `5월 29일 인증`
3. 첫 메시지에 인증 안내 카드 생성
4. `오늘 인증` 버튼 제공

### 5.3 기본 인증 플로우

1. 사용자가 오늘의 인증 쓰레드를 연다.
2. `오늘 인증` 버튼을 누른다.
3. 시스템이 이번 주 목표를 조회한다.
4. 목표가 없으면 목표 작성으로 유도한다.
5. 목표가 있으면 목표 기반 인증 폼을 동적으로 생성한다.

### 5.4 인증 폼 동작

인증 폼은 목표 항목에 따라 다르게 구성된다.

예:

- 체크형 목표는 체크 여부 입력
- URL형 목표는 링크 입력
- 사진형 목표는 파일 업로드
- 텍스트형 목표는 설명 입력

정책:

- 오늘 수행한 항목만 선택해 제출 가능
- 모든 목표 항목이 매번 필수는 아님

### 5.5 인증 완료 후 결과

1. 시스템이 인증 데이터를 저장한다.
2. 해당 일일 쓰레드에 인증 카드 메시지를 생성한다.
3. 사용자에게는 완료 안내를 보낸다.

### 5.6 추가 인증 플로우

1. 사용자가 같은 날 다시 `오늘 인증` 버튼을 누른다.
2. 시스템은 기존 기록을 유지한다.
3. 새 인증 내용을 추가 저장한다.
4. 쓰레드에는 새 인증 카드가 추가로 생성된다.
5. 집계 시 같은 날짜 안의 인증을 누적 처리한다.

### 5.7 마감 플로우

1. 다음 날 04:00이 되면 해당 일자의 인증 쓰레드는 마감 상태가 된다.
2. 이후 인증 제출은 차단된다.
3. 차단된 기록은 리더보드에 반영하지 않는다.

## 6. `#리더보드` UX 플로우

### 6.1 목적

`#리더보드`는 주간 결과 발표 채널이다.

형태:

- 포럼 채널

### 6.2 리더보드 글 생성

1. 매주 월요일 00:00에 새 포럼 글 생성
2. 제목: `5월 4주차 리더보드`
3. 첫 메시지에 주간 요약 카드 생성

### 6.3 리더보드 카드 내용

- 참여 인원
- 전체 평균 달성률
- Top 3
- Bottom 3
- 전체 순위표

### 6.4 사용자 열람 흐름

1. 사용자가 리더보드 포럼 글을 연다.
2. 첫 메시지에서 이번 주 순위를 확인한다.
3. 필요하면 상세 순위 또는 내 위치를 추가 버튼으로 본다.

## 7. 관리자 UX 플로우

### 7.1 목표

관리자는 명령어 문법 없이 채널/시간 정책을 설정할 수 있어야 한다.

### 7.2 설정 진입

권장 진입점:

- `#스터디-홈` 카드의 `서버 설정` 버튼

### 7.3 설정 항목

- 목표 포럼 생성 시각
- 인증 쓰레드 생성 시각
- 리더보드 생성 시각
- 채널 매핑
- 타임존

### 7.4 설정 변경 흐름

1. 관리자가 설정 버튼 클릭
2. 설정 카드 또는 선택 UI 오픈
3. 항목별 모달 또는 셀렉트로 수정
4. 저장 후 요약 카드 갱신

## 8. 오류/예외 UX

### 목표 없이 인증 시도

- 메시지: `이번 주 목표가 없습니다. 먼저 이번 주 목표를 작성해 주세요.`
- 액션: `목표 작성하러 가기`

### 이미 목표 작성 완료

- 메시지: `이번 주 목표를 이미 작성했습니다.`
- 액션: `내 목표 보기`, `수정`

### 마감 이후 인증 시도

- 메시지: `오늘 인증 마감 시간이 지났습니다.`

### 권한 없는 설정 시도

- 메시지: `이 기능은 서버 관리자만 사용할 수 있습니다.`
